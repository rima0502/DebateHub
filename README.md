
# 💬 DebateHub (디베이트허브)

![DebateHub Hero](https://picsum.photos/seed/debate-banner/1200/400)

**DebateHub**는 실시간 숙의형 토론을 위한 지능형 공론장 플랫폼입니다. 구조화된 토론 규칙과 검증된 익명성을 통해 건강한 토론 문화를 지향합니다.

## ✨ Key Features

- **🔥 Real-time Hot Debates**: 참여자 수 기반 실시간 인기 토론 자동 노출
- **💬 Structured Chat**: 찬성(PRO) / 반대(CON) 진영별 메시지 시각화 및 답글 기능
- **🚀 Easy Creation**: 누구나 직관적으로 새로운 논제를 발의하고 공론장 개설
- **📱 Responsive Design**: 모바일과 데스크탑 어디서든 최적화된 토론 경험
- **🛡️ Moderation Tools**: 사용자 신고 및 활동 상태 실시간 동기화

## 🛠 Tech Stack

- **Core**: React 19, TypeScript
- **Routing**: React Router 7
- **Styling**: Tailwind CSS
- **Icons**: Google Material Symbols
- **Storage**: Browser LocalStorage

## 📂 Project Structure

```text
.
├── pages/              # 각 화면 컴포넌트 (Home, Room, Create 등)
├── types.ts            # 프로젝트 공통 타입 정의
├── App.tsx             # 라우팅 및 레이아웃 설정
├── index.html          # 메인 엔트리 포인트 (CDN 방식)
├── package.json        # 의존성 및 스크립트 설정
└── tsconfig.json       # TypeScript 설정
```

## 🚀 Getting Started

이 프로젝트는 빌드 도구 없이도 동작하도록 설계되었지만, 로컬 개발을 위해 다음 명령어를 사용할 수 있습니다.

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```
